# 04-Kubernetes

## Table of Contents
This directory is designed to organize knowledge related to Kubernetes, focusing on the following areas:
- Architecture and Core Components
- Resource Objects
- Networking, DNS, and Storage
- Application Deployment and Business Containerization
- Operations, GatewayAPI, Helm, KubeVirt

## Current Design Principles
- Organize underlying principles and business implementation in a hierarchical manner
- Strengthen the main thread of "application deployment / business containerization / troubleshooting loop"
- Maintain scalability for future continuous development
