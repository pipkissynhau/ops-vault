# 04-Kubernetes

## Directory Overview
This directory is used to consolidate Kubernetes-related knowledge, with a focus on:
- Architecture and Core Components
- Resource Objects
- Networking, DNS, Storage
- Application Deployment and Business Containerization
- Operations, GatewayAPI, Helm, KubeVirt

## Current Design Principles
- Layered organization of underlying principles and business implementation
- Strengthen the main line of "Application Deployment / Business Containerization / Troubleshooting Loop"
- Maintain extensibility for continuous consolidation in the future
